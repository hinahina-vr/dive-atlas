Map rendering: MapLibre GL JS (BSD-3-Clause).
https://maplibre.org/
Package and version are pinned in package-lock.json; no copied distribution is committed.

Basemap tiles and glyphs: OpenFreeMap.
https://openfreemap.org/
Geographic data: OpenStreetMap contributors (ODbL), OpenMapTiles schema.
https://www.openstreetmap.org/copyright
https://openmaptiles.org/
Attribution links are displayed with the map.

assets/map-style.json is an original, compact style. Island and other geographic names are read from the vector tile place/water_name layers. No dive logs are uploaded to these map providers.

Okinawa island gazetteer: GeoNames JP country dump, CC BY 4.0.
https://download.geonames.org/export/dump/JP.zip
https://www.geonames.org/
https://creativecommons.org/licenses/by/4.0/
Downloaded 2026-11-05; filtered to geographic island features in 25.7-27.3 N / 126.7-128.6 E. Only the filtered 109 labels are included. Japanese island-name variants are selected from the source alternate names. No user dive-log text is used to construct these map labels.
